ctfshow 命令执行web71

web1

题目来源：ctfshow 命令执行web71
题目链接(https://d1861ff1-df3f-4df8-af5f-b1d1dbde1b0b.challenge.ctf.show/)
解题思路：
启动靶机

禁用了PHP里改配置和显示代码的三个函数（error_reporting、ini_set、highlight_file）
下载index.php文件 查看

ob_get_contents() 是 PHP 的内置函数，作用就是获取当前输出缓冲区里的所有内容，并以字符串形式返回
ob_end_clean() 是 PHP 内置的输出控制函数，属于 Output Control 函数族,清空（丢弃）当前输出缓冲区的内容，并关闭输出缓冲机制
POST传入参数c 把c的值当作PHP代码直接执行（eval($c)），但执行结果会被截获并把它里面的所有字母数字都替换成问号再输出
整个流程如下：

解决方法：文件内容进入输出缓冲区后强制把缓冲区内容立即发送到浏览器
ob_flush()是 PHP 内置的输出控制函数，作用是强制将当前输出缓冲区中的内容立即发送到浏览器（或Web服务器），同时保留缓冲区继续可用
payload:c=include('/flag.txt');ob_flush();
注意加分号，因为在php语句中，要以分号结束语句
这是两条PHP语句，用分号 ; 分隔，按顺序执行：
1.第一条语句：include('/flag.txt') 读取文件到缓冲区
2.第二条语句：ob_flush()  强制发送缓冲区内容

得到flag

web2

题目来源：ctfshow 命令执行web73
题目链接(27969079-1323-481f-a2c4-df63a3fb24ba.challenge.ctf.show)
解题思路：
启动靶机

同样禁用了PHP里改配置和显示代码的三个函数（error_reporting、ini_set、highlight_file）
POST传入参数c=var_export(scandir('/'));ob_flush();
用上一题的payload

发现没有这个文件
读取根目录看看var_export(scandir('/')); 扫描根目录，然后把扫描结果以合法的 PHP 数组格式打印到页面上

发现flagc.txt文件
读取该文件 用include()函数 POST传入参数`c=include(“/flagc.txt”);ob_flush(); ``

得到flag

另外一种做法

include 执行完，文件内容被输出 exit() 立即终止脚本，阻止 index.php 后续代码继续执行
区别：exit() 是读完文件直接终止整个脚本，只输出flag，干净利落；ob_flush() 只是手动把缓冲区内容刷出去，但脚本继续往下跑
