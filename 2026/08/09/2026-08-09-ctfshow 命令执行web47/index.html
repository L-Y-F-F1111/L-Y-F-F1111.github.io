题目描述：
解题思路：
启动靶机

正则过滤了; cat flag 空格 所有数字 $ * more less head sort tail
和上一题相比多过滤了more/less/head/sort/tail 这些是 Linux系统中的文本查看和处理命令
more 是Linux中最基础的分页查看器，用于逐页浏览文件内容，适合查看大文件。
less 是 more 的增强版本，功能更强大，是双向分页查看器
head查看文件头部
sort对文件内容进行排序并显示
tail查看文件尾部

依旧用tac绕过
所以payload:?c=tac%09fla?.php||

得到flag
这里我先尝试了?c=tac%09fla?||,因为web45我尝试空格替代方法的时候省去了.php,但是这题省略之后得不到flag，猜测是有多个fla开头的文件影响了输出。

解题思路：
启动靶机

正则过滤了分号 cat flag 空格 所有数字 $ * more less head sort tail sed cut awk string od curl 反引号
这里more, less, head, sort, tail, sed, cut, awk, strings, od是查看命令
反引号是禁止命令替换 反引号会先执行其中的命令，然后将执行结果替换到原来的位置
sed功能强大的文本处理工具，可以查找、替换、删除文本
cut剪切文本,从每行中提取特定部分
awk强大的文本分析工具，可以按列处理数据
strings从二进制文件中提取所有可打印的字符串
od以八进制、十六进制等格式显示文件内容
curl 是一个网络传输工具，支持多种协议（HTTP、HTTPS、FTP、SFTP、SMTP等），用于在命令行下发送和接收网络请求

题目来源：ctfshow 命令执行web49
题目链接(https://d4d8f0d1-e0f1-409c-870f-236dbca1eaef.challenge.ctf.show/)
题目描述：
解题思路：
启动靶机

正则过滤了分号 cat flag 空格 所有数字 $ * more less head sort tail sed cut awk strings od curl 反引号 %
尝试用<

payload:?c=tac<fla?.php||
这里还是同样的问题 通配符搭配重定向符号使用时，可能会遇到重定向匹配多个文件，这时会影响输出

payload:?c=tac<fla\g.php||
fla\g.php 中的序列是：f→l→a→\→g ，a 后面是 \，不是 g 所以绕过对flag的过滤
并且fla\g.php \g 被Shell转义，在Shell中，\g表示字符 g 本身

得到flag

注意
查看wp时发现 payload:?c=tac%09fla?.php||仍然适用

原因：URL解码发生在正则过滤之前
URL解码之后%09被转为了tab键 绕过了对空格以及百分号的过滤
